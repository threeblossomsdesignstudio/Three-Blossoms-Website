HOW TO UPDATE GITHUB PAGES
1. Extract the ZIP.
2. Visit github.com/threeblossomsdesignstudio/Three-Blossoms-Website
3. Upload ALL of the files/folders inside this ZIP to the repository ROOT.
   Overwrite index.html, portfolio.html, and styles.css when prompted;
   keep the assets files inside the assets folder.
4. Commit the changes to main.
5. Wait for GitHub Pages to redeploy and refresh the browser.
